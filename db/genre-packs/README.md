# Genre packs

Each file here is a starting point for the Assistant (api/assistant.php): a short note on how one kind of game reads,
which a GM picks in Settings, Assistant. The first line is the pack's name; the rest is sent to the model with every
request, ahead of the campaign's own guide, which wins wherever the two differ.

A pack describes a genre, never a published setting: no names, places, creatures or rules text from anyone's game.
Keep one under about 200 words, and write it as advice to a co-writer.
