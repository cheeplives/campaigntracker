# Maps phase 3: build plan

Spec: `docs/superpowers/specs/2026-11-06-maps-phase-3-design.md`.

1. Database: `031_map_nesting.sql`, `schema.sql`, `upgrade.php` step, campaign copy maps `child_map_id`.
2. API (`api/maps.php`, `api/index.php`): `pin_save` takes `child_map_id` (GM only, same campaign, not its own map);
   `pin_out` gives `child_map` (hidden from players when GM-only); `map` returns `parent`.
3. Page (`static/maps.js`): *Opens map* in the pin form, link on the pin card, *Inside:* line under the title.
4. Detection (`static/mapgeo.js`): `detectGrid(gray, w, h)`; Node unit tests on synthetic pictures.
5. Page: *Find the grid* and the automatic run in the scale dialog, the preview overlay, the offset saved with the scale.
6. Tests: API test for the link and its secrecy; browser tests for the pin form → card → inner map → back, and for
   detection on a gridded and a plain picture.
